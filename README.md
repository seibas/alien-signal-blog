# Alien Signal Blog (Next.js)

A futuristic coding blog with Italian translation support.

🚀 **Status**: Live with all features configured!

## Run
```bash
npm install
npm run dev
```

Open http://localhost:3000

## Pages
- `/` Home (animated hero)
- `/about` About page
- `/blog` Blog index
- `/blog/[slug]` Blog post

Posts live in `content/posts.js`.
